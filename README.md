# VI Planer

Тестовый прототип единого портфеля **проектов и продуктов** со сквозным приоритетом (WSJF) и расчётом ETA по ёмкости команд.

## Проблема, которую закрывает

В исходной схеме проекты и продукты лежат в разных бэклогах, поэтому:

1. нет общей очереди приоритетов между потоками;
2. одни и те же команды загружены «невидимо» друг для друга;
3. нельзя честно ответить «когда закончим» с учётом ёмкости.

## Что внутри

| Вкладка | Смысл |
|---|---|
| **Портфель** | Проекты + продукты в одном списке, исходный бэклог сохранён как метка |
| **Очереди команд** | Сквозной приоритет внутри каждой команды |
| **Сроки / Gantt** | ETA после выстраивания очереди под weekly capacity |
| **Ёмкость** | What-if: двигаете FTE — сроки пересчитываются |

Модель приоритета: **WSJF = (Business Value + Time Criticality + Risk/Opportunity) / Job Size**. Можно задать ручной ранг.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Постоянная ссылка в Google Workspace (рекомендуется для коллег)

В папке [`gas/`](gas/) лежит готовый Web App:

1. [script.new](https://script.google.com) → новый проект
2. Вставьте `Code.gs` и создайте HTML-файл `Index` с содержимым `gas/Index.html`
3. Deploy → New deployment → Web app  
   - Execute as: Me  
   - Who has access: Anyone in vitech.team (или нужный круг)
4. Скопируйте URL коллегам

Данные каждого браузера в `localStorage`. Чтобы синхронизировать снимок — **Экспорт / Импорт JSON**.

## Демо-туннель

Пока крутится `npm run preview` на этой машине, временная ссылка может быть поднята через localhost.run. Для постоянной работы используйте GAS или свой хостинг `dist/`.
