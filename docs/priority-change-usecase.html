Изменение приоритета функциональности

Use-case VI Planer: решение ТОПов → смена сквозного приоритета (manualRank) → пересчёт расписания → оповещение. Одна команда vs кросс-командная функциональность.

Ветки

Одна команда

  • Приоритет в общей нумерации 1…n
  • Пересчёт старта / завершения этой работы
  • Сдвиг следующих в очереди команды

Несколько команд

  • Один сквозной manualRank
  • Пересчёт очередей всех назначенных команд
  • Дата завершения = max по трекам (bottleneck)
